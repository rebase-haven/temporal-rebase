# Momo 桌面宠物

一个运行在 Windows 桌面的轻量陪伴宠物。Momo 常驻在桌面上，可以互动、切换陪伴模式，并根据电脑正在播放的音乐节拍跳舞。角色采用温馨的二次元 chibi 女仆风格，以深蓝长发、蕾丝发箍和黑白裙装呈现；界面使用 Python 与 Tkinter 实现。

## 功能特色

- **桌面陪伴**：透明置顶、可拖动的宠物窗口，不占用任务栏空间。
- **宠物互动**：点击回应并触发动作；右键打开快捷菜单；双击宠物打开控制面板。
- **多种陪伴模式**：陪伴、专注、休息；模式会影响宠物的提示语。
- **音乐律动**：通过 Windows 音频回环读取默认播放设备的声音，以低频能量变化检测节拍，并根据音量调整舞蹈幅度。
- **六种舞步**：自由律动、弹跳、左右摇摆、转身、踢踏、派对，可从控制面板循环切换。
- **手动跳舞**：不启用音乐跟随也能预览舞蹈动作。

## 环境要求

- Windows 10 或 Windows 11
- Python 3.10 或更新版本，并包含 Tkinter
- `soundcard`、`numpy`、`Pillow`（可通过安装脚本安装）

## 安装与启动

1. 克隆仓库或下载 ZIP 并解压。
2. 双击 `安装依赖.bat` 安装 Python 依赖。
3. 双击 `启动宠物.bat` 启动 Momo。
4. 在控制面板选择陪伴模式，点击“开始跟随系统音乐”启用音乐律动。

也可以从终端运行：

```powershell
python -m pip install -r requirements.txt
python pet.py
```

## 操作方式

| 操作 | 效果 |
| --- | --- |
| 点击宠物 | 抚摸并触发回应动作 |
| 拖动宠物 | 移动宠物在桌面上的位置 |
| 双击宠物 | 打开设置控制面板 |
| 右键宠物 | 打开设置、手动跳舞、隐藏或退出菜单 |
| 控制面板的“舞步”按钮 | 循环切换六种舞步 |

## 常见问题

- **安装时报 Python 命令不存在**：安装 Python 3.10+，安装时启用 PATH 选项，然后重新打开终端或双击启动脚本。
- **音乐音量条没有变化**：检查电脑是否正在播放声音，并确认 Windows 默认输出设备正确。切换音频输出设备后，重启宠物再试。
- **可以看到音量，但舞步不明显**：在控制面板循环切换舞步；较安静的音源可能需要调高播放音量。
- **双击启动后立即关闭**：从 PowerShell 进入项目目录运行 `python pet.py`，查看具体错误信息；也可先重新运行 `安装依赖.bat`。

## 文件结构

```text
pet.py              宠物窗口、互动、角色绘制与音频节拍检测
requirements.txt    Python 依赖列表
安装依赖.bat        安装依赖的 Windows 脚本
启动宠物.bat        启动应用的 Windows 脚本
```

音乐跟随仅在运行时读取默认输出设备的回环音频，不录制或保存声音。若音频驱动不支持回环采集，手动跳舞和宠物互动仍可使用。
